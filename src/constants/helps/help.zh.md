# AblaufDiagramm 帮助

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Z` | 撤销上一步操作 |
| `Ctrl + Y` / `Ctrl + Shift + Z` | 重做已撤销的操作 |
| `Ctrl + D` | 复制选中的节点（支持多选） |
| `Delete` / `Backspace` | 删除选中的节点或连线（输入框中无效） |
| `Ctrl + A` | 全选所有人物节点 |
| `Ctrl + =` / `Ctrl + +` | 放大画布 |
| `Ctrl + -` | 缩小画布 |
| `Escape` | 取消所有选中 / 取消拖线中的连线 |
| `Space + Drag` | 按住空格拖拽平移画布 |
| `Mouse Wheel` | 缩放画布（10% ~ 1000%） |
| `Ctrl + Click` | 多选 / 取消多选节点 |
| `Drag on empty canvas` | 框选多个节点 |

## 操作指南

### 添加节点

1. 点击左侧窄工具栏的 `+`，在画布创建一个新人物节点。
2. 选中一个节点后，点击左侧工具栏的 `↳` 或节点上下文工具条的 `+`，在其下方创建子节点并自动以父子关系连线。
3. 选中一个节点后，点击节点上下文工具条的 `⇄`，在其旁边创建配偶节点并自动以夫妻关系连线。
4. 节点上下文工具条还提供 `⧉` 复制节点和 `×` 删除节点两个快捷动作。

### 选择节点与连线

1. 点击节点可选中该节点，节点周围会出现蓝色选择框。
2. 点击连线可选中该连线，按需出现的右侧属性检查器会显示连线属性。
3. 点击画布空白位置会取消当前选中，节点选择框会消失。
4. 按住 `Ctrl` 点击节点可进行多选或取消单个节点选中。
5. 在画布空白处拖拽可框选多个节点。

### 创建连线

1. 鼠标悬停节点边缘，会出现上下左右四个连接点。
2. 从连接点拖出连线到目标节点的连接点上释放。
3. 拖线前在左侧窄工具栏 `⇄` 关系菜单中选择关系类型：**父子关系** 或 **夫妻关系**。
4. 连线颜色继承自源节点的自定义颜色；选中连线时高亮为蓝色。
5. 点击空白区域可取消拖线中的连线。

### 属性检查器

选中节点后，按需出现的右侧属性检查器可编辑以下属性：

| 字段 | 说明 |
| --- | --- |
| 头像 | 节点左侧嵌入图片，支持输入 URL（http/https/data URI）或点击上传按钮导入本地图片 |
| 标题 | 节点第一行，加粗显示 |
| 副标题1 | 节点第二行 |
| 副标题2 | 节点第三行 |
| 身份 | 节点身份信息 |
| 时间 | 节点时间信息 |
| 附加信息 | 额外文字（可选） |
| 编号圆标 | 右上角圆形标签文字（可选） |
| 节点颜色 | 自定义节点底色 |
| 位置 | 节点在画布世界坐标中的 X / Y |

选中连线后，可修改关系类型（父子/夫妻）或删除该连线。

### 节点尺寸

- 无头像节点固定为 `180 × 100`。
- 有头像节点固定为 `270 × 120`。
- 通过添加、导入、编辑头像等方式改变节点时，都会收敛到上述两种尺寸。

### 保存与导出

| 功能 | 说明 |
| --- | --- |
| 自动保存 | 编辑时自动保存到浏览器本地存储（localStorage） |
| 导出 JSON | 将当前项目导出为 `.json` 文件，含节点、连线、视口状态和画布边界 |
| 导入 JSON | 从 `.json` 文件恢复完整项目 |
| 导出 PNG | 将完整画布导出为 PNG 位图 |
| 导出 SVG | 将完整画布导出为 SVG 矢量图 |
| 导出 WebP | 将完整画布导出为 WebP 格式 |

图片导出基于离屏导出对象执行，`html-to-image` 不直接截取用户正在操作的真实画布，因此导出时不会临时移动或改写真实画布。

### 小地图

- 右下角小地图显示画布全局缩略图。
- 蓝色矩形框表示当前可视区域。
- 可直接拖拽蓝色框快速导航到任意位置。
- 点击 `-` / `+` 按钮可折叠或展开小地图。

### 缩放面板

- 点击工具栏百分比数字，弹出缩放面板。
- 支持 `-` / `+` 按钮、滑动条和直接百分比输入，精确控制缩放（10% ~ 1000%）。

### 画布尺寸调整

- 点击顶部工具栏的 **画布** 按钮，直接打开画布尺寸调整面板。
- 支持向上、下、左、右四个方向伸展或收缩画布边界。
- 可调节每次伸展或收缩的步长。

### 网格吸附对齐

- 拖拽节点时可自动吸附到网格交点。
- 同时可与附近节点的边缘或中心对齐，并显示橙色辅助线。
- 可在设置中开关此功能。

### 调试者模式

- 调试者模式在设置弹窗中开关，默认开启。
- 调试者模式开启时，**视图** 菜单会显示 **查看克隆画布** 和 **CPP状态**。
- 调试者模式开启时，按需出现的属性检查器会显示块 ID、边 ID、边的源/目标 ID、块的相连边 ID。
- **CPP状态** 弹窗用于查看 C++ GraphCore 的节点、连线和诊断输出。
- **查看克隆画布** 弹窗用于查看幕后克隆画布的缩略图。

### 编辑器布局

- 顶部工具栏按 **文件**、**编辑**、**视图**、**画布**、设置和帮助组织常用命令。
- 左侧窄工具栏提供添加节点、添加子节点、选择关系类型和查看图统计的快捷入口。
- 节点上下文工具条在单选节点时显示，提供添加子节点、添加配偶节点、复制节点和删除节点。
- 右侧属性检查器仅在选中节点或连线后出现；打开时可拖拽调整宽度，宽度会自动保存。

### 项目标题

- 双击工具栏中间的标题文字可重命名项目。
- 按 Enter 确认，按 Escape 取消。
- 标题会出现在导出文件名中。

## 节点类型

| 类型 | 说明 |
| --- | --- |
| **人物节点** | 可见的矩形节点，包含标题、副标题、身份、时间等信息，支持头像、编号圆标和颜色 |

## 小贴士

- 所有连线均为直角正交路径，颜色继承源节点的自定义颜色。
- 点击画布空白位置可以快速取消节点或连线选中。
- 按住 `Ctrl` 可逐个点选多个节点；在空白画布拖拽可框选。
- 画布缩放范围：10% ~ 1000%，可通过滚轮、触控板或 `Ctrl+=` / `Ctrl+-` 快捷键操作。
- 顶部菜单提供导入导出、撤销/重做、删除、复制、适应视图、网格开关、主题切换和开发者工具等常用操作。
- 所有设置（主题、语言、网格、吸附对齐、节点默认颜色、调试者模式）即时生效并自动保存。
