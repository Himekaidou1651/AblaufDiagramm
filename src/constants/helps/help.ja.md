# AblaufDiagramm 手引き

## 鍵盤操作

| 操作 | 動作 |
| --- | --- |
| `Ctrl + Z` | 直前の操作を元に戻す |
| `Ctrl + Y` / `Ctrl + Shift + Z` | 元に戻した操作をやり直す |
| `Ctrl + D` | 選択した節点を複製する（複数選択対応） |
| `Delete` / `Backspace` | 選択した節点または関係線を削除する。入力欄では無効 |
| `Ctrl + A` | すべての人物節点を選択する |
| `Ctrl + =` / `Ctrl + +` | 表示を拡大する |
| `Ctrl + -` | 表示を縮小する |
| `Escape` | 選択解除 / 作成中の関係線を取り消す |
| `Space + Drag` | Space を押しながら引き動かして画布を移動する |
| `Mouse Wheel` | 画布の表示を拡大縮小する（10% ～ 1000%） |
| `Ctrl + Click` | 複数選択 / 個別節点の選択解除 |
| `Drag on empty canvas` | 空白部分を引き動かして複数節点を範囲選択する |

## 操作案内

### 節点を追加する

1. 左側の小型工具列で `+` を押し、画布に新しい人物節点を作成します。
2. 節点を選び、左側工具列の `↳` または節点用の上下文工具列の `+` を押すと、下に子節点を作成し、自動で親子関係を接続します。
3. 節点を選び、節点用の上下文工具列の `⇄` を押すと、横に配偶者節点を作成し、自動で配偶者関係を接続します。
4. 節点用の上下文工具列には、`⧉` による複製と `×` による削除もあります。

### 節点と関係線を選択する

1. 節点を押すと選択され、青い選択枠が表示されます。
2. 関係線を押すと選択され、右側の属性確認欄に関係線の属性が表示されます。
3. 画布の空白部分を押すと、現在の選択が解除されます。
4. `Ctrl` を押しながら節点を押すと、複数選択または個別の選択解除ができます。
5. 空白部分を引き動かすと、複数節点を範囲選択できます。

### 関係線を作成する

1. 節点の端に指示矢印を重ねると、上下左右に4つの接続点が表示されます。
2. 接続点から引き動かし、対象節点の接続点上で手を離します。
3. 引き動かす前に、左側工具列の `⇄` 関係選択欄で、**親子関係** または **配偶者関係** を選びます。
4. 関係線の色は接続元節点の任意指定色を受け継ぎます。選択中の関係線は青色で強調されます。
5. 画布の空白部分を押すと、作成中の関係線を取り消せます。

### 属性確認欄

節点を選ぶと、右側の属性確認欄で以下の属性を編集できます。

| 項目 | 説明 |
| --- | --- |
| 肖像 | 左側に埋め込まれる画像。URL（http/https/data URI）入力または本地画像の読込に対応 |
| 題名 | 節点の1行目。太字で表示 |
| 副題1 | 2行目 |
| 副題2 | 3行目 |
| 身分 | 身分の文字 |
| 時間 | 時間の文字 |
| 追加情報 | 任意の追加文字 |
| 標識 | 右上の円形標識に表示する任意の文字 |
| 節点色 | 任意指定の背景色 |
| 位置 | 画布世界座標における節点の X / Y |

関係線を選ぶと、種類（親子 / 配偶者）の変更または削除ができます。

### 節点の大きさ

- 肖像なしの節点は `180 × 100` に固定されます。
- 肖像ありの節点は `270 × 120` に固定されます。
- 肖像の追加、読込、編集を行うと、常にこの2種類の大きさのいずれかに整えられます。

### 保存と書出

| 機能 | 説明 |
| --- | --- |
| 自動保存 | 編集中に閲覧器の本地記憶（localStorage）へ自動保存 |
| JSON 書出 | 現在の案件を `.json` として書き出す。節点、関係線、表示状態、画布範囲を含む |
| JSON 読込 | `.json` から完全な案件を復元する |
| PNG 書出 | 画布全体を PNG 画像として書き出す |
| SVG 書出 | 画布全体を SVG 向量画像として書き出す |
| WebP 書出 | 画布全体を WebP 形式で書き出す |

画像の書出は画面外の書出用物体で実行されます。`html-to-image` は操作中の実画布を直接取得したり一時的に書き換えたりしないため、表示中の画布が跳ねることはありません。

### 小地図

- 右下の小地図には画布全体の縮小表示が表示されます。
- 青い矩形は現在表示中の範囲を示します。
- 青い矩形を引き動かすと、任意の位置へすばやく移動できます。
- `-` / `+` を押すと、小図を折りたたみまたは展開できます。

### 拡大縮小欄

- 工具列の割合表示を押すと、拡大縮小欄が開きます。
- `-` / `+`、滑動条、または割合の直接入力で表示倍率を調整できます（10% ～ 1000%）。

### 画布の大きさ調整

- 上部工具列の **画布** を押すと、大きさ調整欄が開きます。
- 上、下、左、右の4方向に画布の境界を拡大または縮小できます。
- 各調整の刻み幅を設定できます。

### 格子吸着整列

- 節点を引き動かすと、格子の交点へ自動で吸着できます。
- 近くの節点の辺や中心にも整列でき、橙色の補助線が表示されます。
- この機能は設定で切り替えられます。

### 開発者様式

- 開発者様式は設定欄で切り替えられ、初期状態では有効です。
- 有効時、**表示** 選択欄に **複製画布を表示** と **CPP状態** が表示されます。
- 有効時、属性確認欄に区画識別子、関係線識別子、接続元 / 接続先識別子、接続中の関係線識別子が表示されます。
- **CPP状態** は C++ GraphCore の節点、関係線、診断出力を表示します。
- **複製画布を表示** は裏側の複製画布の縮小事前表示を表示します。

### 編集器の配置

- 上部工具列は **書類**、**編集**、**表示**、**画布**、設定、手引きに指令をまとめています。
- 左側の小型工具列には、節点追加、子節点追加、関係種類選択、図の統計表示への近道があります。
- 節点用の上下文工具列は単一節点選択時に表示され、子節点追加、配偶者追加、複製、削除を提供します。
- 右側属性確認欄は節点または関係線を選択した後にのみ表示されます。開いている間は幅を変更でき、自動保存されます。

### 案件名

- 工具列中央の題名を二度押すと、案件名を変更できます。
- Enter で確定し、Escape で取り消します。
- 案件名は書出書類名に含まれます。

## 節点の種類

| 種類 | 説明 |
| --- | --- |
| **人物節点** | 題名、副題、身分、時間などを含む表示用の矩形節点。肖像、標識、任意指定色に対応 |

## 注意点

- すべての関係線は直角の直交経路を使い、色は接続元節点の任意指定色を受け継ぎます。
- 画布の空白部分を押すと、節点または関係線の選択をすばやく解除できます。
- `Ctrl` を押しながら押すと複数節点を個別に選択できます。空白部分を引き動かすと範囲選択できます。
- 画布の表示倍率は 10% ～ 1000% で、回転輪、触控板、`Ctrl+=` / `Ctrl+-` で操作できます。
- 上部の選択欄には読込と書出、元に戻す / やり直し、削除、複製、表示調整、格子、様式切替、開発者用機能があります。
- すべての設定は直ちに反映され、自動保存されます。
