# دليل AblaufDiagramm

## اختصارات لوحة المفاتيح

| Shortcut | Action |
| --- | --- |
| `Ctrl + Z` | التراجع عن آخر عملية |
| `Ctrl + Y` / `Ctrl + Shift + Z` | إعادة العملية المتراجَع عنها |
| `Ctrl + D` | تكرار العقدة المحددة أو العقد المحددة |
| `Delete` / `Backspace` | حذف العقدة أو الرابط المحدد، ويُتجاهل داخل حقول النص |
| `Ctrl + A` | تحديد جميع عقد الأشخاص |
| `Ctrl + =` / `Ctrl + +` | تكبير العرض |
| `Ctrl + -` | تصغير العرض |
| `Escape` | إلغاء التحديد / إلغاء رابط قيد الإنشاء |
| `Space + Drag` | اضغط Space ثم اسحب لتحريك اللوحة |
| `Mouse Wheel` | تكبير أو تصغير اللوحة (10% ~ 1000%) |
| `Ctrl + Click` | تحديد متعدد أو إلغاء تحديد عقدة بشكل منفصل |
| `Drag on empty canvas` | سحب على مساحة فارغة لتحديد عدة عقد |

## دليل الاستخدام

### إضافة العقد

1. انقر `+` في الشريط الأيسر المختصر لإنشاء عقدة شخص جديدة على اللوحة.
2. حدِّد عقدة ثم انقر `↳` في الشريط الأيسر أو `+` في شريط سياق العقدة لإنشاء عقدة طفل أسفلها مع رابط والد/طفل تلقائي.
3. حدِّد عقدة ثم انقر `⇄` في شريط سياق العقدة لإنشاء عقدة زوج/زوجة بجانبها مع رابط زوجي تلقائي.
4. يتيح شريط سياق العقدة أيضًا `⧉` لتكرار العقدة و`×` لحذفها.

### تحديد العقد والروابط

1. انقر على عقدة لتحديدها؛ سيظهر إطار تحديد أزرق حولها.
2. انقر على رابط لتحديده؛ ستظهر خصائصه في لوحة الفاحص اليمنى.
3. انقر على مساحة فارغة لإلغاء التحديد الحالي وإخفاء إطار التحديد.
4. اضغط `Ctrl` أثناء النقر على العقد لتحديد متعدد أو إلغاء تحديد فردي.
5. اسحب على مساحة فارغة لتحديد عدة عقد دفعة واحدة.

### إنشاء الروابط

1. مرّر فوق حافة العقدة لإظهار أربع مقابض اتصال: الأعلى، الأسفل، اليسار، اليمين.
2. اسحب من أحد المقابض وأفلته على مقبض عقدة هدف.
3. قبل السحب، اختر نوع العلاقة من قائمة العلاقات في الشريط الأيسر: **والد/طفل** أو **زوجية**.
4. يرث لون الرابط لون العقدة المصدر المخصص، وتُبرز الروابط المحددة باللون الأزرق.
5. انقر على مساحة فارغة لإلغاء رابط قيد الإنشاء.

### فاحص الخصائص

عند تحديد عقدة، تظهر لوحة الفاحص اليمنى وتتيح تعديل الخصائص التالية:

| Field | Description |
| --- | --- |
| Avatar | صورة مضمنة في الجهة اليسرى، تدعم URL أو رفع صورة محلية |
| Title | السطر الأول من العقدة ويظهر بخط عريض |
| Subtitle 1 | السطر الثاني |
| Subtitle 2 | السطر الثالث |
| Identity | نص الهوية |
| Time | نص الوقت |
| Extra Info | نص إضافي اختياري |
| Badge | نص شارة دائرية في أعلى اليمين اختياري |
| Node Color | لون خلفية العقدة المخصص |
| Position | إحداثيات X / Y للعقدة في مساحة اللوحة |

عند تحديد رابط، يمكنك تغيير نوع العلاقة أو حذفه.

### أحجام العقد

- العقد من دون صور رمزية ثابتة عند `180 × 100`.
- العقد مع الصور الرمزية ثابتة عند `270 × 120`.
- إضافة بيانات الصورة الرمزية أو استيرادها أو تعديلها يعيد ضبط الحجم تلقائيًا إلى أحد هذين المقاسين.

### الحفظ والتصدير

| Feature | Description |
| --- | --- |
| Auto Save | يحفظ تلقائيًا إلى التخزين المحلي للمتصفح أثناء التحرير |
| Export JSON | يصدّر المشروع الحالي كملف `.json` يتضمن العقد والروابط وحالة العرض وحدود اللوحة |
| Import JSON | يستعيد مشروعًا كاملًا من ملف `.json` |
| Export PNG | يصدّر اللوحة كاملة كصورة PNG |
| Export SVG | يصدّر اللوحة كاملة كصورة SVG |
| Export WebP | يصدّر اللوحة كاملة كصورة WebP |

يعمل التصدير على كائن تصدير منفصل، ولا يغيّر اللوحة التفاعلية الظاهرة.

### الخريطة المصغرة

- تعرض الخريطة المصغرة في الزاوية اليمنى السفلية صورة مصغرة عالمية للوحة.
- يوضح المستطيل الأزرق المنطقة المرئية الحالية.
- اسحب المستطيل الأزرق للتنقل السريع إلى أي موضع.
- انقر زر `-` أو `+` لطي الخريطة المصغرة أو توسيعها.

### لوحة التكبير

- انقر نسبة التكبير في الشريط العلوي لفتح لوحة التكبير.
- اضبط التكبير بدقة عبر أزرار `-` و`+`، أو منزلق، أو إدخال مباشر للنسبة (10% ~ 1000%).

### تغيير حجم اللوحة

- انقر **Canvas** في الشريط العلوي لفتح لوحة تغيير الحجم مباشرة.
- وسّع أو صغّر حدود اللوحة في أربعة اتجاهات: أعلى، أسفل، يسار، يمين.
- اضبط مقدار الخطوة لكل عملية.

### المحاذاة الشبكية

- يمكن للعقد الالتصاق بنقاط الشبكة أثناء السحب.
- يمكنها أيضًا المحاذاة مع حواف أو مراكز العقد المجاورة، مع خطوط إرشاد برتقالية.
- فعّل هذه الميزة من الإعدادات.

### وضع المطور

- يتم التحكم في وضع المطور من نافذة الإعدادات، وهو مفعّل افتراضيًا.
- عند تفعيله، تظهر في قائمة **View** خيارات **View Clone Canvas** و**CPP Status**.
- عند تفعيله، يعرض الفاحص السياقي معرّفات الكتلة والرابط والمصدر/الهدف والروابط المتصلة.
- تعرض **CPP Status** مخرجات عقدة GraphCore والروابط والتشخيص.
- تعرض **View Clone Canvas** معاينة مصغرة للوحة النسخة المخفية.

### تخطيط المحرر

- يجمع الشريط العلوي الأوامر ضمن **File** و**Edit** و**View** و**Canvas** وSettings وHelp.
- يوفر الشريط الأيسر المختصر إجراءات سريعة لإضافة العقد، إضافة الأبناء، اختيار نوع العلاقة، وفتح إحصاءات الرسم.
- يظهر شريط سياق العقدة عند تحديد عقدة واحدة ويوفر الإضافة والنسخ والحذف.
- تظهر لوحة الفاحص اليمنى بعد تحديد عقدة أو رابط فقط، ويمكن تغيير عرضها وحفظه تلقائيًا.

### عنوان المشروع

- انقر نقرًا مزدوجًا على العنوان في وسط الشريط العلوي لإعادة تسمية المشروع.
- اضغط Enter للتأكيد وEscape للإلغاء.
- يظهر العنوان في أسماء الملفات المصدرة.

## أنواع العقد

| Type | Description |
| --- | --- |
| **Person Node** | عقدة مستطيلة مرئية تحتوي على عنوان وعناوين فرعية وهوية ووقت، وتدعم الصورة الرمزية والشارة واللون المخصص |

## نصائح

- جميع الروابط تستخدم مسارات بزوايا قائمة، ويرث لونها من لون العقدة المصدر.
- انقر على مساحة فارغة لإلغاء تحديد العقدة أو الرابط بسرعة.
- اضغط `Ctrl` لتحديد عدة عقد بشكل فردي؛ واسحب على مساحة فارغة لتحديد مجموعة.
- نطاق التكبير من 10% إلى 1000% عبر عجلة الفأرة أو لوحة اللمس أو `Ctrl+=` و`Ctrl+-`.
- توفر القوائم العلوية الاستيراد والتصدير والتراجع والإعادة والحذف والنسخ وملاءمة العرض وتبديل الشبكة والمظهر وأدوات المطور.
- تُطبق جميع الإعدادات فورًا وتُحفظ تلقائيًا.
