# Справка AblaufDiagramm

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Ctrl + Z` | Отменить последнее действие |
| `Ctrl + Y` / `Ctrl + Shift + Z` | Повторить отменённое действие |
| `Ctrl + D` | Дублировать выбранные узлы, включая множественный выбор |
| `Delete` / `Backspace` | Удалить выбранные узлы или связь; в полях ввода не действует |
| `Ctrl + A` | Выбрать все узлы персонажей |
| `Ctrl + =` / `Ctrl + +` | Увеличить масштаб |
| `Ctrl + -` | Уменьшить масштаб |
| `Escape` | Снять выделение / отменить создаваемую связь |
| `Space + Drag` | Удерживайте Space и перетаскивайте, чтобы перемещать холст |
| `Mouse Wheel` | Масштабировать холст (10% ~ 1000%) |
| `Ctrl + Click` | Множественный выбор / снятие выбора с отдельного узла |
| `Drag on empty canvas` | Выделить несколько узлов рамкой |

## Руководство

### Добавление узлов

1. Нажмите `+` на компактной левой панели, чтобы создать новый узел персонажа на холсте.
2. Выберите узел, затем нажмите `↳` на левой панели или `+` на контекстной панели узла, чтобы создать дочерний узел ниже и автоматически соединить его связью родитель-ребёнок.
3. Выберите узел, затем нажмите `⇄` на контекстной панели узла, чтобы создать рядом узел супруга и автоматически соединить его супружеской связью.
4. Контекстная панель узла также содержит `⧉` для дублирования и `×` для удаления узла.

### Выбор узлов и связей

1. Нажмите на узел, чтобы выбрать его; вокруг узла появится синяя рамка.
2. Нажмите на связь, чтобы выбрать её; контекстный инспектор справа покажет свойства связи.
3. Нажмите на пустую область холста, чтобы очистить текущий выбор.
4. Удерживайте `Ctrl` и нажимайте на узлы для множественного выбора или снятия выбора.
5. Перетащите по пустой области холста, чтобы выбрать несколько узлов рамкой.

### Создание связей

1. Наведите курсор на край узла, чтобы показать четыре точки соединения сверху, снизу, слева и справа.
2. Перетащите от точки соединения и отпустите на точке целевого узла.
3. Перед перетаскиванием выберите тип связи в меню `⇄` на левой панели: **Родитель-ребёнок** или **Супруги**.
4. Цвет связи наследуется от пользовательского цвета исходного узла; выбранные связи подсвечиваются синим.
5. Нажмите на пустую область холста, чтобы отменить создаваемую связь.

### Инспектор свойств

Когда выбран узел, справа появляется контекстный инспектор, где можно редактировать следующие свойства:

| Поле | Описание |
| --- | --- |
| Аватар | Встроенное изображение слева; поддерживает URL (http/https/data URI) или загрузку локального изображения |
| Заголовок | Первая строка узла, отображается жирным |
| Подзаголовок 1 | Вторая строка |
| Подзаголовок 2 | Третья строка |
| Идентичность | Текст идентичности |
| Время | Текст времени |
| Дополнительная информация | Необязательный дополнительный текст |
| Значок | Необязательный круглый значок в правом верхнем углу |
| Цвет узла | Пользовательский цвет фона |
| Позиция | X / Y узла в мировых координатах холста |

Когда выбрана связь, можно изменить её тип (Родитель-ребёнок / Супруги) или удалить её.

### Размеры узлов

- Узлы без аватара имеют фиксированный размер `180 × 100`.
- Узлы с аватаром имеют фиксированный размер `270 × 120`.
- Добавление, импорт или редактирование аватара всегда приводит узлы к одному из этих двух размеров.

### Сохранение и экспорт

| Функция | Описание |
| --- | --- |
| Автосохранение | Автоматически сохраняет изменения в локальное хранилище браузера (localStorage) |
| Экспорт JSON | Экспортирует текущий проект в файл `.json`, включая узлы, связи, состояние вида и границы холста |
| Импорт JSON | Восстанавливает полный проект из файла `.json` |
| Экспорт PNG | Экспортирует весь холст как PNG-изображение |
| Экспорт SVG | Экспортирует весь холст как SVG-вектор |
| Экспорт WebP | Экспортирует весь холст в формате WebP |

Экспорт изображения выполняется через внеэкранный объект экспорта. `html-to-image` не захватывает и не изменяет временно реальный интерактивный холст, поэтому экспорт не должен вызывать скачков видимого холста.

### Мини-карта

- Мини-карта в правом нижнем углу показывает общий миниатюрный вид холста.
- Синий прямоугольник показывает текущую видимую область.
- Перетащите синий прямоугольник, чтобы быстро перейти к любой позиции.
- Нажмите `-` / `+`, чтобы свернуть или развернуть мини-карту.

### Панель масштаба

- Нажмите на процент в панели инструментов, чтобы открыть панель масштаба.
- Настраивайте масштаб кнопками `-` / `+`, ползунком или прямым вводом процента (10% ~ 1000%).

### Изменение размера холста

- Нажмите **Холст** на верхней панели, чтобы открыть панель изменения размера.
- Расширяйте или сжимайте границы холста вверх, вниз, влево или вправо.
- Настраивайте размер шага для каждого изменения.

### Привязка и выравнивание

- При перетаскивании узлы могут автоматически привязываться к пересечениям сетки.
- Узлы также могут выравниваться по краям или центрам соседних узлов; при этом показываются оранжевые направляющие.
- Эту функцию можно включить или выключить в настройках.

### Режим разработчика

- Режим разработчика управляется в окне настроек и включён по умолчанию.
- Когда он включён, меню **Вид** показывает **Просмотр клонированного холста** и **CPP Status**.
- Когда он включён, контекстный инспектор показывает ID блоков, ID связей, ID источника/цели и ID подключённых связей.
- **CPP Status** показывает вывод узлов, связей и диагностики C++ GraphCore.
- **Просмотр клонированного холста** показывает миниатюру скрытого клонированного холста.

### Макет редактора

- Верхняя панель группирует команды в **Файл**, **Правка**, **Вид**, **Холст**, Настройки и Справка.
- Компактная левая панель содержит быстрые действия для добавления узлов, добавления дочерних узлов, выбора типа связи и просмотра статистики графа.
- Контекстная панель узла появляется при выборе одного узла и предлагает добавить ребёнка, добавить супруга, дублировать и удалить.
- Правый инспектор появляется только после выбора узла или связи; его ширину можно изменять, и она сохраняется автоматически.

### Название проекта

- Дважды щёлкните название в центре панели инструментов, чтобы переименовать проект.
- Нажмите Enter для подтверждения, Escape для отмены.
- Название используется в именах экспортируемых файлов.

## Типы узлов

| Тип | Описание |
| --- | --- |
| **Узел персонажа** | Видимый прямоугольный узел с заголовком, подзаголовками, идентичностью, временем и т. д.; поддерживает аватар, значок и пользовательский цвет |

## Советы

- Все связи используют ортогональные прямоугольные пути и наследуют цвет исходного узла.
- Нажмите на пустую область холста, чтобы быстро снять выбор узла или связи.
- Удерживайте `Ctrl`, чтобы выбирать несколько узлов по одному; перетаскивайте по пустой области для рамочного выбора.
- Диапазон масштаба холста: 10% ~ 1000%, через колесо мыши, тачпад или `Ctrl+=` / `Ctrl+-`.
- Верхние меню содержат импорт/экспорт, отмену/повтор, удаление, дублирование, подгонку вида, сетку, переключение темы и инструменты разработчика.
- Все настройки вступают в силу сразу и автоматически сохраняются.
